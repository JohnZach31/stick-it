# Build stamp

The corner tag of the app (bottom right) reads `v<version> dev · build <N> · <date time>`. `N` is the commit count (it goes up with every commit), so the live GitHub Pages site and any local copy can always be told apart.

`js/build-info.js` is generated by `tools/stamp-build.mjs`. A local git hook (`.git/hooks/pre-commit`) runs it on every commit and adds the file to that commit. Hooks are not part of the repository: on a new machine run `printf '#!/bin/sh\nnode tools/stamp-build.mjs >/dev/null 2>&1 && git add js/build-info.js\nexit 0\n' > .git/hooks/pre-commit` once, or run `node tools/stamp-build.mjs` by hand before committing.
