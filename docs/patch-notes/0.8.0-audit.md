## Tests run for this patch
SQL/RLS 362 + 6 new mutations, billing/repo 198, client 142, protocol 41, functions 89, cutout maths 17, object rules 24, collaboration rules 18. Browser: insertion menu (desktop right-click, edge, Esc, outside, native menu kept while typing), Cutout Maker (auto, Erase, Restore, Edges, undo, Use cutout, failure panel, Use original), style cycling and reload, mounted materials, strip creation/editing, postcard edit/flip/undo, receipts/tickets, soup (free gate, premium, text read once), comments and review with the real migrations, duplicate/move, public share (cutout finish, scraps), snapshot export light/dark, 52-object performance board, mobile insertion, dark mode.

## Screenshots seen during the run (not checked in)
