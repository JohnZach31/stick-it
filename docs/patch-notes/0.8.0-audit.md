## Release-candidate polish pass (UI / UX / interaction)
Done on the same v0.8.0: nothing here is a new feature, it is the finishing of what v0.8.0 already added. **S** = shipped, **P** = partial.

### Performance, before and after
Same local board (`tools/perf-fixture.js`: 55 objects, 12 large photos, 4 soup notes, receipts, tickets, postcards, strips, a recording and a video), same browser; before = commit `5ef7325`.

| Measure | Before | After |
|---|---|---|
| DOM nodes | 1,345 | 1,438 (+7%: soup bowls, media extras, the Done pile button) |
| JS heap | 9.8 MB | 7.7 MB |
| Decoded picture memory (18 pictures) | 45.8 MB | 6.2 MB (the pictures need about 2.4 MB) |
| Running animations (soups on screen) | 33 | 16 (1 with the soups scrolled out of view) |
| Dragging one note, 120 pointer moves | 222 ms | 23 ms |
| Minimap rebuilds during that drag (DOM changes) | 6,897 | 0 |
| Permanent animation-frame loops | none | none |

Active event listeners are not inspectable from outside the page, so no number is claimed for them.
