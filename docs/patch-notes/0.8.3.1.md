# Stick-It v0.8.3.1 — Finish the Edges

Release date: not released
Status: **development** (a PATCH release)

A polish pass for the new v0.8.3 surfaces.

## Done feels more done
- Done Space gets a slightly stronger completed identity: a brighter, warmer desk and a few faint hand-drawn motifs (a check stamp, a ribbon, a seal, a star)
- The motifs are decoration only: very low contrast, never animated, and they never receive clicks

## Trash looks like Trash
- Tiny Stick-It-style trash cans, a basket and crumpled paper in the background, sparse and quiet, in light and dark
- Still quiet enough to keep the content readable

## Clippings know where they came from
- Add, edit or remove a source link after creation: ••• → Source (Add / Edit / Remove, Open, Copy). The editor takes the link and an optional source title; Cancel changes nothing
- "No source link" is now a button (a tap on a phone) that opens the editor
- Only http(s) links are accepted; anything else is refused with a message

## Better source icons
- A small, extensible registry recognises ChatGPT, OpenAI, Gemini, Google, YouTube / youtu.be, BBC, GitHub, Reddit and Wikipedia (and their subdomains, such as en.m.wikipedia.org), with the site name and colour
- The registry holds names and colours only: no hand-drawn copies of anyone's logo
- Fallback order: known site → favicon (only if a favicon service is configured; none is by default, see below) → a letter badge → a plain link icon
- A failed icon is remembered so it is not asked for again, and never breaks a clipping

## Layering actually layers
- Root cause: a selected object was forced to a very high z-index (9996, !important) while selected, so it always looked in front even after "Send backward". Selecting an object no longer changes where it sits; its z-index is its layer. Its controls are reachable by pointing at it or keyboard-focusing it
- Also: merely clicking an object no longer raises it (it used to, which silently undid "Send to back"); picking it up and dragging still does
- Bring forward / front, Send backward / back were checked across notes, clippings, shopping lists, photos, receipts, piles and zones

## Shopping List polish
- The Comment tab is placed from the receipt paper's own lower edge (not the whole node with the cart), a little higher and in from the left, with only a few pixels tucked under the paper
- Re-placed whenever the paper changes size

## Small UI consistency fixes
- One row interaction for the Legal & policies rows and the System rows: a warm tint on hover, no underline, the arrow leans in, a clear focus ring, a stronger tint when pressed, and a dark-mode version

## Technical notes (for the team)
- **Favicons:** nothing fetches a favicon today. Asking a favicon service (or the site) would tell a third party which sites you keep clippings of, and the page's security policy would also need to allow it. The resolver is built and tested (`Stick.sources.faviconUrl`, cache with success and failure memory) and is off until `FAVICON_SERVICE` is set in `js/config.js` to an https address containing `{host}`, together with a matching `img-src` entry: an owner/privacy decision.
- **Layering:** one stack, one rule: `z` is the layer. Hovering an object when nothing is selected still lifts it while the pointer is on it (as before).
