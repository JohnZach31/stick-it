# Stick-It v0.8.3.2 — Finish the Flow

Release date: not released
Status: **development** (a PATCH release)

A finishing pass for the things that should feel obvious once they exist.

## Paste it your way
- Choose Sticky Note or Clipping when pasting text
- Remember your preferred choice
- Change it later in Settings

## Newspapers got pictures
- Add an image
- Replace/remove it
- Switch between color and black-and-white

## Done feels better
- Slightly stronger completion effect
- New Done sound

## Trash sounds like Trash
- Subtle discard sound
- Restore gets its own return sound

## Shopping Lists are editable again
- Fixed the editing regression across item text/details

## Legal got another design pass
- Cleaner in-app legal reader
- Better tabs, controls, document spacing and mobile layout

## Zones became real containers
- Larger/freer sizing
- See which objects belong to a zone
- Minimize a zone with all its contents
- Restore everything safely

## Piles look more physical
- Better mixed-node presentation
- Physical navigation controls
- Cleaner member index

## Smarter dates
- Better natural Hebrew and English date/time phrase recognition

## Collaboration got faster
- Add multiple invite emails
- Enter/comma creates email pills
- Paste several addresses at once

## Safer sign-out
- Sign out now asks for confirmation

## Tutorial keyboard navigation
- Enter/Right = Next
- Backspace/Delete/Left = Previous

## Reactions got room to breathe
- Reaction control no longer fights with the ... menu
- Quick reactions plus a broader emoji picker
- Native emoji rendering

## Double-click your way
- Choose which node double-click creates
- Or ask every time

## Receipt cleanup
- Styles now live under Style
- Receipts can be marked Done

## Every patch inside Stick-It
- Browse the full patch history
- Read full notes
- Replay old patch tutorials
- Same structured patch data can power the website too
