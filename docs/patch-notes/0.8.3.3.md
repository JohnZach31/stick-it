# Stick-It v0.8.3.3 — Sand the Edges

Release date: not released
Status: **development** (a hotfix release)

A hotfix for the interactions that were technically working but still felt wrong.

## Tutorial fixes
- Enter/arrow navigation works reliably
- Skip no longer leaves the app behind a dark overlay
- Patch tours can be replayed safely

## Patch history is easier to find
- Browse the full release history
- Read every patch
- Replay supported update tours

## Done feels better
- Completion sound is warmer and more satisfying

## Reactions got redesigned
- Cleaner physical reaction UI
- Better spacing
- Full emoji picker remains available

## Collaboration polish
- Better email-pill spacing and wrapping

## Zones cleaned up
- Shorter menu
- Material and Colour submenus
- Better title visibility
- Clickable object count
- Improved title fonts and cursor behavior

## Empty means empty
- Closing a brand-new empty note no longer sends junk to Trash

## Newspaper fixes
- Copy/paste behaves consistently
- Styles are more visually distinct
- Cleaner style/picture menus

## Smarter paper trimming
- Obvious unused paper trims automatically
- Undo remains immediately available

## Piles rebuilt visually
- The old floating arrows are gone; the index tabs and a physical leaf-through browser replace them
- Cleaner physical browsing
- No overlapping controls
- Mixed node types behave better
- Visible pile member can be edited

## Legal pages caught up
- Standalone legal pages now use the updated visual system too
- Legal text still comes from one canonical source

## Cleaner account/settings UI
- Redundant Change Photo button removed
- Settings rows finally use one interaction system
- Guests no longer see Sign out

## Better Video creation
- Upload
- Paste video link
- Record with camera

## Modal layering fixed
- Confirmations always appear above Done/Trash/system spaces

## Cutout errors make more sense
- Screenshots/documents now get a more useful failure explanation

## Clean Up understands Zones
- Optionally tidy inside Zones without pulling objects out

## Smaller system-space controls
- Done and Trash stay quickly accessible without stealing canvas space

## Print / Save as PDF
- Print one note, or only the items you selected
- Share window and menus offer Print and Print / Save as PDF
- The system print dialog can save the result as a PDF
- Comments, reactions and the rest of the board are never printed

## Better board creation
- New Board belongs with your boards, not underneath system spaces
